# TIL

## 2026-11-23
- `ClassNotFoundException`: the JVM can't find the `.class` → run `javac` first or check the package/folder.
## 2026-11-27
- Pass-by-value: Java always passes a copy → a method can change the object but not the original variable
- `StackOverflowError` = stack full (infinite recursion). `OutOfMemoryError` = heap full (too many objects).
